# API reference

Generated from the TypeScript sources of the published packages:

- **`@lonca/core`**: shared errors, pagination helpers, money and the transport.
- **`@lonca/trendyol`**: the Trendyol client and its types.
- **`@lonca/hepsiburada`**: the Hepsiburada client and its types.
- **`@lonca/n11`**: the n11 client (REST and SOAP) and its types.

Pick a package in the sidebar or from the [package list](/api/modules/). For task-oriented docs, start with the
[guides](/guides/trendyol/).
