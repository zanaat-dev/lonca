`@lonca/n11` 1.0.0: the n11 SDK leaves beta. The public API is the same as the last 0.x release, so no code changes are needed; from now on breaking changes ship only in major versions (see Stability & versioning). Every method has run against n11: the reads on a live seller account, the writes on n11's test store, with order writes, the collection request and return decisions on real test orders.
