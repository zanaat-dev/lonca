`@lonca/n11` 1.0.0: the n11 SDK leaves beta. The public API is the same as the last 0.x release, so no code changes are needed; from now on breaking changes ship only in major versions (see Stability & versioning). Reads are verified on a live seller account; product writes, settlements, address lookups and order writes on n11's test store, the order writes on a paid test order.
